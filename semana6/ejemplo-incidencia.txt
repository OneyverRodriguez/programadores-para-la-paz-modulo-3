Repuesta a la Actividad 8: Prueba de API con Express.js, Simular un registro comunitario

Se solicitó crear un servidor web utilizando Express.js que cumpliera con los siguientes requisitos:

1. Configurar un servidor Node.js con el framework Express
2. Crear una ruta HTTP POST en el endpoint "/registro"
3. Recibir datos JSON con los campos nombre y mensaje
4. Procesar los datos recibidos
5. Devolver una respuesta JSON que confirme la recepción de los datos
6. El servidor debe ejecutarse en el puerto 3000

Desarrollo de la Actividad:

Se creó un servidor Express (server.js) con la siguiente estructura:

1. Inicialización y Configuración del Servidor. Se configura Express para manejar solicitudes JSON y se define la ruta POST para recibir los datos.

const express = require('express');
const app = express();
app.use(express.json());


app.post('/incidencia', (req, res) => {

  const tipo = req.body.tipo;
  const descripcion = req.body.descripcion;

  res.json({
    mensaje: "Incidencia registrada",
    tipo: tipo,
    descripcion: descripcion
  });
});

La ruta extrae los datos del cuerpo de la solicitud y los devuelve en la respuesta.

2. Inicio del Servidor
app.listen(3000, () => {
    console.log('Servidor ejecutándose en puerto 3000');
});
El servidor inicia en el puerto 3000 y muestra un mensaje de confirmación.
